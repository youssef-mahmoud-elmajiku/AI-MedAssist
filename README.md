# AI MedAssist

A portfolio project concept exploring clinical decision-support workflows across medical imaging and ECG analysis.

## Project scope

The portfolio describes a multi-modal system with CT neuroimaging visualization using Grad-CAM, ECG classification, and a unified API/UI workflow. These are project-scope descriptions, not clinical validation claims.

## Technologies listed in the portfolio

- Python 3.12 and FastAPI
- ResNet-50 and Grad-CAM
- 1D CNN for ECG analysis
- React 19 and PySide6

## Status

This repository currently contains project documentation only. Source code, datasets, evaluation results, and clinical validation evidence are not included. Do not use this project for diagnosis or treatment decisions.
